# Binary Tree Zigzag Level Order Traversal

**Difficulty:** Medium

**Source:** LeetCode 103 — Binary Tree Zigzag Level Order Traversal

## Description

Given the `root` of a binary tree, return its zigzag level-order traversal: left-to-right on the first level, right-to-left on the next, alternating thereafter.

## Hint

Do a normal level-order BFS but reverse the values on odd-indexed levels.
