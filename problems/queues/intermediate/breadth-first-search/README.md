# Breadth-First Search (BFS)

BFS explores a graph in layers using a FIFO queue: dequeue a node, enqueue its unvisited neighbors, and repeat. Because it visits nodes in order of increasing distance, it computes shortest paths in *unweighted* graphs in O(V+E).
