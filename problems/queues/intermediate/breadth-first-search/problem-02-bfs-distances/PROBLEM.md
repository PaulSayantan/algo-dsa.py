# BFS Distances From a Source

**Difficulty:** Medium

**Source:** Classic — single-source BFS distances

## Description

Given `n` nodes, an undirected edge list, and a source `src`, return the array of shortest-path distances (in edges) from `src` to every node; use `-1` for unreachable nodes.

## Hint

Standard BFS from src, recording distance when each node is first enqueued.
