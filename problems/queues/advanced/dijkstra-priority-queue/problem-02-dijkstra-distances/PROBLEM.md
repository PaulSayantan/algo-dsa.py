# Dijkstra Distance Array

**Difficulty:** Medium

**Source:** Classic — single-source Dijkstra

## Description

Given `n` nodes, an undirected weighted edge list `[u, v, w]` (w ≥ 0), and a source `src`, return the shortest-distance array from `src` (use `-1` for unreachable nodes).

## Hint

Standard Dijkstra with a min-heap and a finalized-distance array.
