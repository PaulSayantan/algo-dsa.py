# Calendar / Event-Queue Simulation

Many scheduling problems are driven by a time-ordered priority queue of events: pop the earliest, react, and possibly push new events. Meeting-room allocation, for instance, uses a min-heap of meeting end-times to reuse or allocate rooms as each meeting starts.
