# Reverse a Queue

**Difficulty:** Easy

**Source:** Classic — reverse a queue with a stack

## Description

Given a queue represented as a list (front = index 0), return a new list with the elements in reversed order, using a stack: push every element then pop them all back out.

## Examples

### Example 1

```
Input:  q = [1, 2, 3, 4, 5]
Output: [5, 4, 3, 2, 1]
```

## Hint

Push all elements onto a stack; popping yields them in reverse (LIFO).
