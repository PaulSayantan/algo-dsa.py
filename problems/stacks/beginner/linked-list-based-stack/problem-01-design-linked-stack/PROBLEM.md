# Design a Linked-List Stack

**Difficulty:** Easy

**Source:** Classic — linked-list stack ADT

## Description

Implement a LIFO stack using a singly linked list. Insert and remove at the head so `push`, `pop`, `top`, and `size` are all O(1) worst-case.

## Hint

New node's `next` points at the old head; the head is always the top.
