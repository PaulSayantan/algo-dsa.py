# Design a Stack (Array-Backed)

**Difficulty:** Easy

**Source:** Classic — array-backed stack ADT

## Description

Implement a last-in-first-out (LIFO) stack using a dynamic array. Support `push(x)`, `pop()` (remove & return top), `top()` (peek), and `empty()`. All operations must be O(1) amortized.

## Hint

Append to the end of a list for push; pop from the end. The last element is the top.
