# Array-Based Stack

A **stack** is a LIFO (last-in, first-out) container. Backed by a dynamic array, `push`/`pop`/`top`/`empty` are all O(1) amortized — you only ever touch the end of the array. This is the most common concrete stack implementation and the foundation for every stack technique that follows.
