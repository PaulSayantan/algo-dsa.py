# Valid Parentheses Variations

Beyond plain matching, a stack of indices/positions answers a family of parenthesis questions: the longest valid substring, the minimum removals to make a string valid, and validity with a wildcard `*`. Each tracks unmatched positions or ranges of open counts as it scans.

## Problems

| # | Problem | Technique focus | Difficulty |
|---|---------|-----------------|------------|
| 1 | [Longest Valid Parentheses](problem-01-longest-valid-parentheses/PROBLEM.md) | Index stack spans | Hard |
| 2 | [Minimum Remove to Make Valid Parentheses](problem-02-min-remove-to-make-valid/PROBLEM.md) | Delete unmatched parens | Medium |
| 3 | [Valid Parenthesis String](problem-03-valid-parenthesis-string/PROBLEM.md) | Open-count range with `*` | Medium |
| 4 | [Minimum Add to Make Parentheses Valid](problem-04-min-add-to-make-valid/PROBLEM.md) | Count forced insertions | Medium |
| 5 | [Minimum Insertions to Balance a Parentheses String](problem-05-min-insertions-to-balance/PROBLEM.md) | Count forced insertions (2:1 pairing) | Medium |
