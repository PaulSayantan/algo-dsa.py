# Sort a Stack Using One Auxiliary Stack

**Difficulty:** Medium

**Source:** Classic — sort a stack

## Description

You are given a stack represented as a list, where the **last** element is the top. Sort it so that the largest element ends up on top (ascending from bottom to top), using only stack operations and one extra stack. Return the sorted list (bottom to top).

## Hint

Pop from input; before pushing to the temp stack, move temp's larger elements back to the input.
