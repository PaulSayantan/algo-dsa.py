# Binary Tree Preorder Traversal

**Difficulty:** Medium

**Source:** LeetCode 144 — Binary Tree Preorder Traversal

## Description

Given the `root` of a binary tree (built here from a level-order list with `None` for missing children), return its **preorder** traversal as a list of node values — implemented **iteratively** with an explicit stack, not recursion.

## Hint

Push root; pop-visit, then push right child then left child.
