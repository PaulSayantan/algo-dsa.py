# Binary Tree Postorder Traversal

**Difficulty:** Medium

**Source:** LeetCode 145 — Binary Tree Postorder Traversal

## Description

Given the `root` of a binary tree (built here from a level-order list with `None` for missing children), return its **postorder** traversal as a list of node values — implemented **iteratively** with an explicit stack, not recursion.

## Hint

Do a root-right-left walk pushing values, then reverse the result.
