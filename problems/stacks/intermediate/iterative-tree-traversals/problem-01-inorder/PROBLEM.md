# Binary Tree Inorder Traversal

**Difficulty:** Medium

**Source:** LeetCode 94 — Binary Tree Inorder Traversal

## Description

Given the `root` of a binary tree (built here from a level-order list with `None` for missing children), return its **inorder** traversal as a list of node values — implemented **iteratively** with an explicit stack, not recursion.

## Hint

Push all left children, then pop-visit-and-go-right in a loop.
