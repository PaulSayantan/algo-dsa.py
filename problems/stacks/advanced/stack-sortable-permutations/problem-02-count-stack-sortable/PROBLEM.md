# Count Stack-Sortable Permutations

**Difficulty:** Medium

**Source:** Classic — Catalan numbers

## Description

The number of stack-sortable permutations of `1..n` equals the `n`-th Catalan number `C(n) = (2n)! / ((n+1)! n!)`. Given `n`, return that count.

## Examples

### Example 1

```
Input:  n = 3
Output: 5
```

## Hint

Compute the n-th Catalan number, e.g. via the DP recurrence or binomial formula.
