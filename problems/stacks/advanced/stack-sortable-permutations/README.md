# Stack-Sortable Permutations

A permutation is *stack-sortable* iff it can be sorted into `1..n` using a single stack (push in input order, pop to output when the next needed value surfaces). Knuth showed these are exactly the permutations avoiding the 231 pattern, and they are counted by the Catalan numbers.
