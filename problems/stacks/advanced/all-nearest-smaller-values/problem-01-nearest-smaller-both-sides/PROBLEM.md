# Nearest Smaller Values on Both Sides

**Difficulty:** Medium

**Source:** Classic — All Nearest Smaller Values

## Description

Given an array `nums`, return a list of `[left, right]` pairs where `left` is the nearest strictly smaller value to the left of each element (or `-1`) and `right` is the nearest strictly smaller value to the right (or `-1`).

## Hint

One increasing-stack pass left-to-right for the left answers, one right-to-left for the right answers.
