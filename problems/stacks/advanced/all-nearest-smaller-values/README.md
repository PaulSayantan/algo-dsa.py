# All Nearest Smaller Values (ANSV)

ANSV computes, for every array position, the nearest strictly smaller value to its left and to its right — the building block behind largest-rectangle, subarray-min sums, and Cartesian trees. A single monotonic-stack pass per side yields all answers in O(n).
