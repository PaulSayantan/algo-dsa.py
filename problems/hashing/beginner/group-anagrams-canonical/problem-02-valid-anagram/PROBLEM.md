# Valid Anagram

**Difficulty:** Easy

**Source:** LeetCode 242 — Valid Anagram

## Description

Given two strings `s` and `t`, return `true` if `t` is an anagram of `s`, and `false` otherwise. `t` is an anagram of `s` iff it uses exactly the same letters with the same multiplicities.

## Examples

### Example 1

```
Input:  s = "anagram", t = "nagaram"
Output: true
```

### Example 2

```
Input:  s = "rat", t = "car"
Output: false
```

## Hint

Two strings are anagrams iff their character-count maps are equal.
