# Intersection of Three Sorted Arrays

**Difficulty:** Easy

**Source:** LeetCode 1213 — Intersection of Three Sorted Arrays

## Description

Given three integer arrays `arr1`, `arr2`, and `arr3`, each sorted in **strictly increasing** order, return a sorted array of only the integers that appear in **all three** arrays.

## Examples

### Example 1

```
Input:  arr1=[1,2,3,4,5], arr2=[1,2,5,7,9], arr3=[1,3,4,5,8]
Output: [1,5]
```

## Hint

Intersect the three sets and sort; or advance three pointers together and keep values equal in all three.
