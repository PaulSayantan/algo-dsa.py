# Find the Difference

**Difficulty:** Easy

**Source:** LeetCode 389 — Find the Difference

## Description

String `t` is generated by shuffling string `s` and then inserting one additional lowercase letter at a random position. Return the letter that was added.

## Examples

### Example 1

```
Input:  s = "abcd", t = "abcde"
Output: "e"
```

## Hint

Subtract s's counts from t's; the one leftover letter is the addition.
