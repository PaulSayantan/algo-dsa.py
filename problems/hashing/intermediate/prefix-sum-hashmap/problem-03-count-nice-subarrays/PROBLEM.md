# Count Number of Nice Subarrays

**Difficulty:** Medium

**Source:** LeetCode 1248 — Count Number of Nice Subarrays

## Description

An array is *nice* if it contains exactly `k` odd numbers. Given `nums` and `k`, return the number of contiguous subarrays containing exactly `k` odd numbers.

## Examples

### Example 1

```
Input:  nums = [1,1,2,1,1], k = 3
Output: 2
```

## Hint

Map each value to its parity (odd=1); this becomes Binary Subarrays With Sum = k.
