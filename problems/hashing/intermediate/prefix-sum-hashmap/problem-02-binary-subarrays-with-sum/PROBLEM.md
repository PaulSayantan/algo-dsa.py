# Binary Subarrays With Sum

**Difficulty:** Medium

**Source:** LeetCode 930 — Binary Subarrays With Sum

## Description

Given a binary array `nums` and an integer `goal`, return the number of non-empty contiguous subarrays whose sum equals `goal`.

## Examples

### Example 1

```
Input:  nums = [1,0,1,0,1], goal = 2
Output: 4
```

## Hint

Same prefix-sum frequency map as Subarray Sum Equals K, on a 0/1 array.
