# Find the Duplicate Number (Seen Set)

**Difficulty:** Medium

**Source:** LeetCode 287 — Find the Duplicate Number (seen-set variant)

## Description

Given an array `nums` of `n + 1` integers where each integer is in `[1, n]`, exactly one value is repeated. Return that repeated value. (This variant permits O(n) extra space via a Hash Set.)

## Examples

### Example 1

```
Input:  nums = [1,3,4,2,2]
Output: 2
```

## Hint

Return the first value that is already in the seen set.
