# Identical Trees via Serialization

**Difficulty:** Easy

**Source:** Classic — tree equality by serialization

## Description

Given two binary trees as level-order lists, determine whether they are structurally identical with equal node values, by comparing their canonical serialization strings. Return a boolean.

## Examples

### Example 1

```
Input:  a = [1,2,3], b = [1,2,3]
Output: True
```

## Hint

Serialize both trees the same way and compare the resulting strings.
