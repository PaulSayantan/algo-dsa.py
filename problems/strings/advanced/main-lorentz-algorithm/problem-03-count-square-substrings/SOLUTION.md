# Solution — Count Square Substrings

## Brute Force

Count every `(start, half-length)` pair whose two halves are equal.

```python
def count_square_substrings_brute(s: str) -> int:
    n = len(s); c = 0
    for i in range(n):
        for L in range(1, (n - i) // 2 + 1):
            if s[i:i+L] == s[i+L:i+2*L]:
                c += 1
    return c
```

- **Time:** O(n³) naive, O(n²) with hashing / Z-function.
- **Space:** O(1) extra.

Two problems at scale: the loop itself is O(n²) pairs, and for `"aaaa...a"` the
answer is Θ(n²), so even *emitting* squares individually is too slow.

## Optimal Approach — Main–Lorentz Algorithm

The Main–Lorentz algorithm does **not** enumerate squares individually — that could
be Θ(n²) of them. Instead it produces **O(n log n) ranges**, each meaning:

> "Every start index in `[lo, hi]` begins a square of length `2l`."

Crucially, each such range represents `(hi - lo + 1)` distinct square occurrences,
all counted in **O(1)**. And — this is the key correctness property — the algorithm
emits every square **exactly once** across all ranges. So the answer is simply:

```python
total = 0
for lo, hi, l in square_ranges(s):
    total += hi - lo + 1
return total
```

### Why each square is counted exactly once

A square is classified by the recursion level at which it first crosses a midpoint
(if it lies entirely within a half it is deferred to that half's recursion, where
it either crosses a deeper midpoint or bottoms out). Within a level, a crossing
square is either *left-centered* or *right-centered*, never both. To avoid a square
being generated by both the "left" and "right" scans at the same center, the left
case caps its block length at `l - 1` (`hi = min(hi, l - 1)`). With that guard the
ranges are disjoint over occurrences, so summing sizes gives the exact multiset
count — no double counting, no omissions.

This was validated exhaustively against the O(n³) brute force on all binary strings
up to length 11 and thousands of random ternary strings.

### Complexity

- **Time:** O(n log n) — the range construction dominates; summing is O(#ranges).
- **Space:** O(n) if you accumulate during recursion, O(n log n) if you store ranges.

### Reference implementation

```python
def z_function(s):
    n = len(s); z = [0]*n; l = r = 0
    for i in range(1, n):
        if i < r: z[i] = min(r - i, z[i - l])
        while i + z[i] < n and s[z[i]] == s[i + z[i]]: z[i] += 1
        if i + z[i] > r: l, r = i, i + z[i]
    return z

def _gz(z, i): return z[i] if 0 <= i < len(z) else 0

def square_ranges(S):
    out = []
    def rec(s, shift):
        n = len(s)
        if n < 2: return
        nu = n // 2; nv = n - nu
        u, v = s[:nu], s[nu:]
        rec(u, shift); rec(v, shift + nu)
        z1 = z_function(u[::-1])
        z2 = z_function(v + '#' + u)
        z3 = z_function(u[::-1] + '#' + v[::-1])
        z4 = z_function(v)
        for cntr in range(n):
            if cntr < nu:
                l = nu - cntr
                k1 = _gz(z1, nu - cntr); k2 = _gz(z2, nv + 1 + cntr); left = True
            else:
                l = cntr - nu + 1
                k1 = _gz(z3, nu + 1 + nv - 1 - (cntr - nu)); k2 = _gz(z4, (cntr - nu) + 1); left = False
            if k1 + k2 < l: continue
            lo = max(1, l - k2); hi = min(l, k1)
            if left: hi = min(hi, l - 1)
            if lo > hi: continue
            if left:
                s_lo, s_hi = shift + cntr - hi, shift + cntr - lo
            else:
                s_lo, s_hi = shift + cntr - l - hi + 1, shift + cntr - l - lo + 1
            out.append((s_lo, s_hi, l))
    rec(S, 0)
    return out

def count_square_substrings(s: str) -> int:
    return sum(hi - lo + 1 for lo, hi, l in square_ranges(s))
```

## Key Insights & Edge Cases

- **Never list squares individually.** The whole reason to prefer the ranged
  Main–Lorentz output is that the count itself can be Θ(n²).
- **`aaaa` gives 4, not 3:** `"aa"@0`, `"aa"@1`, `"aa"@2`, and `"aaaa"@0`. Squares
  are counted by `(start, length)`, so `"aa"@0` and `"aaaa"@0` are distinct.
- **The `l - 1` cap in the left case is load-bearing** — remove it and you
  double-count squares whose two centers coincide.
- **Square-free strings** yield `0` (no ranges emitted).
- Distinct-*content* counting is a different, harder problem — see Problem 4.
