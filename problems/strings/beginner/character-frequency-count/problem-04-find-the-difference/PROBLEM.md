# Find the Difference

**Difficulty:** Easy

**Source:** LeetCode 389 — Find the Difference

## Description

You are given two strings `s` and `t`.

String `t` is generated by random shuffling string `s` and then adding **one more
letter** at a random position.

Return the letter that was added to `t`.

## Constraints

- `0 <= s.length <= 1000`
- `t.length == s.length + 1`
- `s` and `t` consist of lowercase English letters.

## Examples

### Example 1

```
Input:  s = "abcd", t = "abcde"
Output: "e"
Explanation: t contains every letter of s (a, b, c, d) plus an extra 'e'. The
             letter 'e' is the one that does not have a matching partner in s.
```

### Example 2

```
Input:  s = "", t = "y"
Output: "y"
Explanation: s is empty, so every letter of t is "extra". The single added letter
             is 'y'.
```

### Example 3

```
Input:  s = "aabb", t = "abbba"
Output: "b"
Explanation: s has a:2, b:2. t has a:2, b:3. The counts match for 'a' but t has one
             more 'b', so 'b' is the added letter.
```

## Hint

The added letter is the one whose count in `t` exceeds its count in `s` by one.
Track a **Character Frequency Count**: add for characters in `t`, subtract for
characters in `s`, and the letter left with a positive tally is the answer.
