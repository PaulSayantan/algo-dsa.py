# Find the Difference

**Difficulty:** Easy

**Source:** LeetCode 389 (Find the Difference)

## Description

You are given two strings `s` and `t`.

String `t` is generated by taking the characters of `s`, shuffling them into a
random order, and then inserting **one additional lowercase letter** at a random
position. So `t` is always exactly one character longer than `s`, and it contains
every character of `s` plus one extra.

Return the single extra letter that was added to `t`.

Because every character is a lowercase letter, you can treat characters as their
integer codes and use ASCII arithmetic: summing the codes of `t` and subtracting
the sum of the codes of `s` leaves exactly the code of the added letter. (An XOR
of all codes works too, and avoids any overflow concerns.)

## Constraints

- `0 <= s.length <= 1000`
- `t.length == s.length + 1`
- `s` and `t` consist of lowercase English letters.

## Examples

### Example 1

```
Input:  s = "abcd", t = "abcde"
Output: "e"
Explanation: The sum of codes of "abcde" minus the sum of codes of "abcd" equals
ord('e') = 101, so chr(101) = 'e' is the added letter.
```

### Example 2

```
Input:  s = "", t = "y"
Output: "y"
Explanation: s is empty, so the whole of t is the added letter.
```

### Example 3

```
Input:  s = "aab", t = "baaa"
Output: "a"
Explanation: t has three 'a's and one 'b'; s has two 'a's and one 'b'. The extra
character is 'a'. XOR-ing all codes of s and t together cancels the matched pairs
and leaves ord('a').
```

## Hint

Use **Case Conversion & ASCII Arithmetic**: convert each letter to its code and
combine the two strings with a reversible operation (sum-difference or XOR) so the
matched characters cancel and only the extra code survives.
